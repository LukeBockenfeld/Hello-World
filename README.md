# 👋 Hello-World: My First GitHub Repository

> A practice repository created for **BAIS:3050 Professional Preparation** to learn how to organize, document, and share project files on GitHub.

---

## 📌 Description

This repository is my first step toward building a **professional portfolio** on GitHub. It contains two sample files from my coursework and a README written in **Markdown** to show how I document my work clearly and professionally.

## 🛠️ Tools Used

- **GitHub**: hosting and version control
- **Markdown**: formatting this README
- **Microsoft Word**: creating written documents
- **Microsoft Excel**: organizing and analyzing data

## 📁 Files Used

| File | Description |
|------|-------------|
| `Professional_Development_Plan.docx` | A career objective, skills to develop, and a 30/60/90-day goal timeline |
| `Skills_Development_Tracker.xlsx` | A spreadsheet tracking my current vs. target skill levels |

## ▶️ How to Run Program

There is no code to run in this repository. To view the files:

1. Click on the file name in the list above
2. Select **Download** (or **View raw**)
3. Open the file in Microsoft Word or Excel
